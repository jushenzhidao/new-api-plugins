# 2026-09-07

## acedata-suno 插件（新建 1.0.0）
- 新建 `plugins/tasks/acedata-suno/1.0.0/plugin.js`：New API Suno 任务格式（`/acedata/suno/submit/music`、`/acedata/suno/submit/lyrics`、`GET /acedata/suno/fetch/:task_id`）异构桥接到 AceDataCloud Suno 上游（`api.acedata.cloud`，Bearer 鉴权）。
- channelType 10007，models `suno_music`/`suno_lyrics`；已登记到 skill 的 channelTypes 表。
- 关键上游契约：提交 `POST /suno/audios`（action generate/extend，custom/prompt/lyric/title/style/instrumental/audio_id/continue_at，恒 `async:true`）与 `POST /suno/lyrics`；查询 `POST /suno/tasks` + `{id, action:"retrieve"}`（不是 GET path param）。
- acedata tasks 响应**无显式状态枚举**：排队=无 started_at；进行中=有 started_at 无 response；成功=response.success + audio_url/text（失败信号优先）；失败=response.error 或 data 项 state 前缀命中失败词。查询期 HTTP 4xx/5xx 全部抛错重试（都是鉴权/限流类，非任务终态）。
- 语义缺口显式拒绝：notify_hook（回调形状不可复刻）、POST /suno/fetch 批量查询（宿主 query 路由必须含 :task_id 占位符）。
- renderer 还原 New API Suno 形状：`{code:"success", data: task_id}` / `{code, message, data:{task_id, action:MUSIC|LYRICS, status:SUBMITTED|IN_PROGRESS|SUCCESS|FAIL, ...}}`；歌词 data 为对象、音乐 data 为歌曲数组；时间戳归一为秒。
- artifact：response.data[] 的 audio/image/video URL，去重 + 稳定 key（audio/audio_2…），credentialless 回源。
- 验证：node --check 通过；85 条合同测试全过（测试文件 `.workbuddy-ai/tmp-tests/acedata-suno.test.mjs`）。

## 真实 curl 提交失败排查与 1.0.5
- 用户实际调用 `POST /suno/submit/music`，提交 `prompt`（多段歌词）、`tags`、`mv: chirp-v5-5`、`title`，返回 `server_error / Task request failed`。
